# Project vision

Kwechiri is an Igbo-first programming language intended to make programming
more accessible to Igbo speakers while remaining compatible with modern
software ecosystems.

It is not merely an English language with translated keywords. Its long-term
identity includes its own specification, compiler stages, runtime abstractions,
standard library, tools, documentation, and educational ecosystem.

The language should be simple, predictable, expressive, extensible,
professional, and authentically African. Its initial TypeScript compiler and
JavaScript/Node.js target are implementation choices, not the definition of the
language itself.
