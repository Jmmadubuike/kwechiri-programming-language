# ADR-001: Kwechiri language name

## Context

The language needs a stable identity across source, tooling, documentation, and
public communication.

## Options considered

The founding project charter established the name before repository
implementation. Renaming alternatives were not part of this stabilization.

## Decision

The official language name is **Kwechiri**.

## Consequences

Documentation, compiler diagnostics, CLI branding, and future tools use
Kwechiri. Any rename is a major owner-controlled product and compatibility
decision.
