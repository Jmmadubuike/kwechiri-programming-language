# Governance and authority

The human project owner is the final authority for language identity, Igbo
terminology, philosophy, syntax, semantics, priorities, public APIs, branding,
licensing, compatibility, publication, and releases.

Engineering work proceeds one explicitly approved milestone or stabilization
scope at a time. Material language decisions require discussion, an owner
decision, documentation, implementation, tests, review, and only then an
approved commit.

`AGENTS.md` contains the binding operational rules. Current specifications and
approved ADRs define established behaviour. Historical milestone documents
provide context but do not override later approved decisions.
