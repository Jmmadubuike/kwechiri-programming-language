## About

Kwechiri is an Igbo-first programming language for learners and builders. It
combines a readable Igbo vocabulary with a professionally tested TypeScript
compiler, a Node.js runtime, a browser playground, and editor tooling. The
project treats Igbo as the language's design foundation while preserving a
clear path to modern software ecosystems.
